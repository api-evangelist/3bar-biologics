# 3Bar Biologics (3BarBio)

> 3Bar Biologics is an agricultural biotechnology company in Columbus, Ohio, spun out of research at
> The Ohio State University, operating as the first contract development and manufacturing
> organization (CDMO) dedicated to agricultural biologicals. Its LiveMicrobe platform — including the
> Iso-Pak and Re-Pak delivery systems — keeps beneficial bacteria viable through storage and
> distribution, the problem that has historically limited adoption of microbial crop inputs.

## What you can and cannot call here

3Bar Biologics publishes NO developer program, NO developer portal, NO API documentation, NO SDKs
and NO pricing for any programmatic product. There is no product API for its biologicals, its
manufacturing capacity, its packaging systems or its supply chain.

The only machine-readable interface the company exposes is the WordPress REST content API behind its
corporate website. It is anonymously readable, read-only, entirely undocumented by the company, and
incidental to the website rather than offered as a product. It returns the company's news archive
and marketing pages — nothing about strains, formulations, batches, viability testing or customers.

This file was generated by API Evangelist from artifacts in this repository. It is not published by
3Bar Biologics.

- Base URL: https://www.3barbiologics.com/wp-json
- Authentication: none for reads. No key, token or account.
- Rate limits: none published, and no rate-limit response headers are returned. Self-throttle.
- Format: application/json. Errors use the WordPress envelope {code, message, data:{status}}, not RFC 9457.

## Conventions

- Pagination: `page` / `per_page` (default 10, max 100) / `offset`. Totals in X-WP-Total and X-WP-TotalPages; RFC 8288 Link header carries rel="next".
- Sparse fields: `_fields=id,slug,title` — worth using, records are ~16KB unfiltered.
- Embedding: `_embed` inlines author, featured media and terms under `_embedded`.
- Filtering: `search`, `slug`, `include`, `exclude`, `after`, `before`, `categories`, `tags`, `author`, `order`, `orderby`.
- Caching: responses declare `Cache-Control: public, max-age=604800` behind Varnish/Fastly. A read may be up to a week stale.
- Every response carries `X-Robots-Tag: noindex`.

## Known defects (verified 2026-09-05, reproduce them yourself before relying on this)

- `GET /wp/v2/media` returns **HTTP 500** for any ascending numeric or date sort (`order=asc`, `orderby=date|id|author`). The body is HTML, not a JSON error envelope. `orderby=title|slug` ascending works, and descending always works. Posts and pages are unaffected.
- `GET /wp/v2/media` advertises `X-WP-Total: 560` but anonymous pages return 0-5 records with HTTP 200. **An empty 200 here does not mean the collection is exhausted.** Page until the Link header stops carrying rel="next".
- `GET /yoast/v1/get_head` returns 404 with a populated, parseable body. Branch on the status code.
- The Careers page is readable through the Pages API but its public URL is an infinite redirect loop.
- The apex domain `3barbiologics.com` serves a certificate that does not cover it. Always use `www.`.
